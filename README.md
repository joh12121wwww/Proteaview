# Proteaview V0.1
Offline-first Android ANPR prototype for Huawei Nova 12i.

## Current milestone
- Rear camera preview
- Camera permission
- Start/Stop ANPR interface
- GitHub Actions APK build

The recognition engine is the next milestone; V0.1 establishes the installable camera application first.

## Build on GitHub
Create a repository, upload this project, then open Actions > Build Proteaview APK > Run workflow. When complete, download the Proteaview-V0.1-APK artifact.
